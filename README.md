# 秋招投递中控台

一个本地优先的中文秋招/校招岗位管理工具，可用于记录岗位、投递状态、优先级、跟进日期、流程节点、备注和简历版本。

## 使用方式

发布到 GitHub Pages 后，直接访问仓库对应的 Pages 链接即可使用。

## 数据与隐私

- 岗位数据保存在访问者自己浏览器的 localStorage 中。
- 简历文件保存在访问者自己浏览器的 IndexedDB 中。
- 仓库和网页托管不包含访问者录入的数据，也不会把数据同步到 GitHub。
- 清理浏览器数据、换浏览器或换设备后，原本地数据不会自动出现，请定期导出 XLSX/CSV 备份。

## 当前能力

- 岗位搜索、统计、筛选和排序；
- 状态、优先级、跟进日期与备注维护；
- 岗位详情中可二次确认后删除单条岗位；
- 岗位详情和投递流程档案；
- CSV/XLSX 导入导出；
- 多工作表历史投递合并；
- 浏览器本地简历版本库。

## 部署

仓库根目录已经包含 `index.html` 和 `assets`，可在 GitHub 仓库设置中选择 Pages 的 `Deploy from a branch`，然后选择 `main` 分支和根目录 `/`。

## 限制

- 当前是纯前端、单用户、本地存储版本；
- 没有账号、云同步、AI 或招聘网站自动进度查询；
- 手机端布局仍以桌面视图为主。
